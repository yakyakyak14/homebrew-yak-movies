# Homebrew Tap for YAK-movies

Stream movies, shows, anime, and live TV from your terminal.

## Compatibility

- macOS 14 through macOS 27+ (Darwin 20 - 27+)
- Full native support for Apple Silicon (rm64) and Intel (x86_64)
- Linux (x86_64 & arm64)

## Installation

### Standard (Universal Prebuilt Binary)
`ash
brew tap yakyakyak14/yak-movies
brew install yak-movies
`

Or install directly with a single command:
`ash
brew install yakyakyak14/yak-movies/yak-movies
`

### Native Build from Source (macOS 27+ / Bleeding-Edge Darwin)
If you are running bleeding-edge macOS 27 / Darwin 27 or prefer compiling natively with your system compiler:
`ash
brew install yakyakyak14/yak-movies/yak-movies-source
`

## Requirements

- Media player: mpv (rew install mpv), VLC, or IINA
