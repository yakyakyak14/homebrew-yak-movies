# Homebrew Tap for YAK-movies

Stream movies, shows, anime, and live TV from your terminal.

## Installation

Tap and install:
\\\ash
brew tap yakyakyak14/yak-movies
brew install yak-movies
\\\

Or install directly with a single command:
\\\ash
brew install yakyakyak14/yak-movies/yak-movies
\\\

## Requirements

- macOS or Linux
- Media player: \mpv\ (\rew install mpv\)
